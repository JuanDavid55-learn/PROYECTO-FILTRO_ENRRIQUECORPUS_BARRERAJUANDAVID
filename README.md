# Panel Administrativo Web - Kario Media

Este proyecto es una propuesta desarrollada para la empresa Kario Media, la cual se dedica a licitaciones públicas y privadas en diferentes sectores. El objetivo fue implementar la primera parte del flujo administrativo siguiendo las indicaciones del equipo de diseño UI/UX.

## Descripción

Se construyó una interfaz web responsiva basada en el diseño proporcionado. El flujo inicia con un login para el ingreso de usuarios administrativos y da acceso al panel principal con diferentes módulos. Este trabajo busca reflejar fielmente la experiencia visual y de navegación planteada por el equipo de diseño.

## Funcionalidades

- Página de inicio de sesión
- Pantalla de bienvenida personalizada
- Panel de indicadores
- Módulo de añadir indicadores
- Módulo de eliminar indicadores
- Módulo de reportes
- Módulo de ayuda
- Acceso al perfil de usuario (configuración y cierre de sesión)
- Versión responsiva para dispositivos móviles

## Tecnologías utilizadas

- HTML5
- CSS3
- Media Queries para diseño adaptativo

## Observaciones

Este proyecto fue desarrollado como parte de un ejercicio formativo, en el cual se aplicaron conocimientos de maquetación web y diseño responsivo. Se priorizó seguir fielmente el diseño entregado, manteniendo la estructura, colores y experiencia definidos por el equipo de UI/UX.
